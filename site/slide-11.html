Simulating 3-Outcome POVMs

Coarse-grained POVM: \[\begin{align} \Pi_{\{i\}} &= \frac{\theta_i}{2\pi}(\mathbb{I} - \frac{\pi \sin{\frac{\theta_i}{2}}}{2 \theta_i}\hat{\lambda}_i \cdot \vec{\sigma}) &= \frac{\theta_i}{2\pi}\mathbb{I} - \frac{1}{4}\hat{\lambda}'_1 \cdot \vec{\sigma}\\ \Pi_{\{i\}^c} &= \frac{\theta_i}{2\pi}(\mathbb{I} + \frac{\pi \sin{\frac{\theta_i}{2}}}{2 \theta_i}\hat{\lambda}_i \cdot \vec{\sigma}) &= \frac{\theta_i}{2\pi}\mathbb{I} + \frac{1}{4}\hat{\lambda}'_i \cdot \vec{\sigma}\end{align}\]

We can simulate \(M_a^{r=\frac{1}{2}}\) with unnormalized response function: \[\begin{align} 2 \mu_1 \Pi_{\{1\}} + 2 \mu_1 \Pi_{\{1, 2\}} + 2 \mu_1 \Pi_{\{1,3\}} &= M_1^{r=\frac{1}{2}} &= \mu_1(\mathbb{I} + \frac{1}{2}\hat{x}_1\cdot\vec{\sigma})\\ 2 \mu_2 \Pi_{\{1,2\}} + 2 \mu_2 \Pi_{\{2\}} + 2 \mu_2 \Pi_{\{2,3\}} &= M_2^{r=\frac{1}{2}} &= \mu_2(\mathbb{I} + \frac{1}{2}\hat{x}_2\cdot\vec{\sigma})\\ 2 \mu_3 \Pi_{\{1,3\}} + 2 \mu_3 \Pi_{\{2,3\}} + 2 \mu_3 \Pi_{\{3\}} &= M_3^{r=\frac{1}{2}} &= \mu_3(\mathbb{I} + \frac{1}{2}\hat{x}_3\cdot\vec{\sigma}) \end{align}\]

We get: \[\begin{align} \mu_1\frac{\theta_1 + \theta_2 + \theta_3}{\pi}\mathbb{I} + \frac{\mu_1}{2}(\hat{\lambda}'_2 + \hat{\lambda}'_3 - \hat{\lambda}'_1)\cdot\vec{\sigma} &= \mu_1\mathbb{I} + \frac{\mu_1}{2} \hat{x}_1 \cdot \vec{\sigma}\\ \mu_2\frac{\theta_1 + \theta_2 + \theta_3}{\pi}\mathbb{I} + \frac{\mu_2}{2}(\hat{\lambda}'_1 + \hat{\lambda}'_3 - \hat{\lambda}'_2)\cdot\vec{\sigma} &= \mu_2\mathbb{I} + \frac{\mu_2}{2} \hat{x}_2 \cdot \vec{\sigma}\\ \mu_3\frac{\theta_1 + \theta_2 + \theta_3}{\pi}\mathbb{I} + \frac{\mu_3}{2}(\hat{\lambda}'_1 + \hat{\lambda}'_2 - \hat{\lambda}'_3)\cdot\vec{\sigma} &= \mu_3\mathbb{I} + \frac{\mu_3}{2} \hat{x}_3 \cdot \vec{\sigma} \end{align}\]

We get: \[\begin{align} \mu_1(\hat{\lambda}'_2 + \hat{\lambda}'_3 - \hat{\lambda}'_1) &= \mu_1 \hat{x}_1\\ \mu_2(\hat{\lambda}'_1 + \hat{\lambda}'_3 - \hat{\lambda}'_2) &= \mu_2 \hat{x}_2\\ \mu_3(\hat{\lambda}'_1 + \hat{\lambda}'_2 - \hat{\lambda}'_3) &= \mu_3 \hat{x}_3 \end{align}\]

\[ (1-2\mu_1)\hat{\lambda}'_1 + (1-2\mu_2)\hat{\lambda}'_2 + (1-2\mu_3)\hat{\lambda}'_3 = \mu_1 \hat{x}_1 + \mu_2 \hat{x}_2 + \mu_3 \hat{x}_3 = 0 \]

Coarse-grained POVM: \[ \Pi_{\{i\}} = \frac{\theta_i}{2\pi}\mathbb{I} - \frac{1}{4}\hat{\lambda}'_1 \cdot \vec{\sigma}\text{, }\quad\Pi_{\{i\}^c} = \frac{\theta_i}{2\pi}\mathbb{I} + \frac{1}{4}\hat{\lambda}'_i \cdot \vec{\sigma} \]

We need to simulate \(M_a^{r=\frac{1}{2}}\) with normalized response function: \[\begin{align} 2 \mu_1 \Pi_{\{1\}} + 2 \mu_1 \Pi_{\{1, 2\}} + 2 \mu_1 \Pi_{\{1,3\}} &= M_1^{r=\frac{1}{2}} &= \mu_1(\mathbb{I} + \frac{1}{2}\hat{x}_1\cdot\vec{\sigma})\\ (1 - 2 \mu_1) \Pi_{\{1,2\}} + \Pi_{\{2\}} + (2 \mu_2 - X) \Pi_{\{2,3\}} + Y \Pi_{\{1\}} &= M_2^{r=\frac{1}{2}} &= \mu_2(\mathbb{I} + \frac{1}{2}\hat{x}_2\cdot\vec{\sigma})\\ (1 - 2\mu_1) \Pi_{\{1,3\}} + (2 \mu_3 - Y) \Pi_{\{2,3\}} + \Pi_{\{3\}} + X \Pi_{\{1\}} &= M_3^{r=\frac{1}{2}} &= \mu_3(\mathbb{I} + \frac{1}{2}\hat{x}_3\cdot\vec{\sigma}) \end{align}\]

Coarse-grained POVM: \[ \Pi_{\{i\}} = \frac{\theta_i}{2\pi}\mathbb{I} - \frac{1}{4}\hat{\lambda}'_1 \cdot \vec{\sigma}\text{, }\quad\Pi_{\{i\}^c} = \frac{\theta_i}{2\pi}\mathbb{I} + \frac{1}{4}\hat{\lambda}'_i \cdot \vec{\sigma} \]

We need to simulate \(M_2^{r=\frac{1}{2}}\) with normalized response function: \[ (1 - 2 \mu_1) \Pi_{\{1,2\}} + \Pi_{\{2\}} + (2 \mu_2 - X) \Pi_{\{2,3\}} + Y \Pi_{\{1\}} = \mu_2(\mathbb{I} + \frac{1}{2}\hat{x}_2\cdot\vec{\sigma}) \]

Coefficients in front of \(\vec{\sigma}\): \[ (1-2\mu_1)\hat{\lambda}'_3 - \hat{\lambda}'_2 + (2\mu_2 - X) \hat{\lambda}'_1 - Y\hat{\lambda}'_1 = 2\mu_2\hat{x}'_2 \]

We already know that: \[ 2\mu_2\hat{\lambda}'_3 - 2\mu_2\hat{\lambda}'_2 + 2\mu_2 \hat{\lambda}'_1 = 2\mu_2\hat{x}'_2 \]

Subtracting, we get: \[ (1-2\mu_1-2\mu_2)\hat{\lambda}'_3 + (2\mu_2-1) \hat{\lambda}'_2 + (-Y - X) \hat{\lambda}'_1 = 0 \]

Which we can rewrite as: \[ (2\mu_3-1)\hat{\lambda}'_3 + (2\mu_2-1) \hat{\lambda}'_2 + (2\mu_1-1) \hat{\lambda}'_1 = 0 \]

Coefficients in front of \(\mathbb{I}\): \[ (1 - 2\mu_1)\frac{\theta_3}{2\pi} + \frac{\theta_2}{2\pi} + (2\mu_2 - X)\frac{\theta_1}{2\pi} + Y\frac{\theta_1}{2\pi} = \mu_2 \]

\[ (1 - 2\mu_1)\theta_3 + \theta_2 + (2\mu_2 - X)\theta_1 + (1 - 2\mu_1 - X)\theta_1 = 2 \mu_2 (\theta_1 + \theta_2 + \theta_3) \]

\[\begin{aligned} X &= \frac{\theta_1(1-2\mu_1) - \theta_2(1-2\mu_2) + \theta_3(1-2\mu_3)}{2\theta_1}\\ Y &= \frac{\theta_1(1-2\mu_1) + \theta_2(1-2\mu_2) - \theta_3(1-2\mu_3)}{2\theta_1} \end{aligned}\]
